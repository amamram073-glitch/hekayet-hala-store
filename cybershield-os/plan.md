# خطة تنفيذ CyberShield OS

## النطاق والقرار المعماري

هذا مشروع مستقل داخل `cybershield-os/` في مستودع متجر قائم، لذا لن يُستبدل تطبيق المتجر. الهدف تسليم أساس MVP قابل للتشغيل والاختبار بوظائف خلفية حقيقية، لا الادعاء بتنفيذ جميع وحدات مواصفات SaaS المؤسسية دفعة واحدة.

- **الواجهة:** React + TypeScript + Vite، عربية افتراضياً، RTL، مع تبديل EN/LTR؛ كل البيانات المعروضة الحساسة تُحمّل من API.
- **الخلفية:** Python 3.12، FastAPI، Pydantic، SQLAlchemy 2، PostgreSQL افتراضياً في Docker Compose، SQLite للاختبارات والتطوير المحلي عند عدم وجود قاعدة Postgres.
- **المعالجة الخلفية:** Celery + Redis للمهام، مع حالات تقدم محفوظة في قاعدة البيانات. لا تُخفي الواجهة تعذّر تشغيل العامل.
- **المصادقة:** Argon2id، JWT قصير العمر داخل Cookie من نوع HttpOnly/SameSite، سجلات جلسات قابلة للإبطال، حماية CSRF، تفويض مركزي على الخادم.
- **الفحص:** وحدات DNS/TLS/HTTP محدودة إلى أصل مصرح به يدوياً. منع عناوين الشبكات الخاصة/المحلية، التحقق من DNS قبل الاتصال، تعطيل التحويلات، مهلات قصيرة، وعدم تنفيذ استغلال أو مسح منافذ/إنترنت.
- **البيانات:** UUID، قيود وفهارس وعلاقات بين المؤسسات والأصول والنتائج والمخاطر والحوادث والأحداث والتدقيق وسجل الدرجات. كل استعلام محمي بسياق المؤسسة.
- **التقارير والذكاء الاصطناعي:** التقارير تُشتق من سجلات المؤسسة. المحلل يستخدم مزود OpenAI-compatible مضبوطاً من البيئة؛ عند غياب الاعتماد يعيد خطأً واضحاً ولا يتظاهر بإجراء تحليل أو تنفيذ إجراء.

## البنية المبدئية

```text
cybershield-os/
  apps/web/                 React UI, صفحات عربية/إنجليزية وعميل API
  apps/api/app/              إعداد FastAPI، المصادقة، الصلاحيات، المسارات
  apps/api/app/models/        نماذج SQLAlchemy
  apps/api/app/services/      الدرجات، الفحص المصرح، التقارير، AI
  apps/api/alembic/           ترحيلات PostgreSQL
  services/worker/            مهام Celery
  infrastructure/docker/      ملفات تشغيل الحاويات وNginx عند الحاجة
  tests/                      اختبارات API وعزل وأمن
  docs/                       توثيق التشغيل والنموذج الأمني
  docker-compose.yml
  .env.example
  README.md, SECURITY.md, CONTRIBUTING.md
```

## وصف التصميم

- **الحركة البصرية:** أدوات أمن مؤسسي معاصرة بطابع تقني هادئ، لا أسلوب ألعاب.
- **المبادئ:** كثافة معلومات مضبوطة؛ إبراز الأولوية والشدّة بوضوح؛ قابلية قراءة عالية بالعربية؛ تمييز صريح بين الملاحظة والاستنتاج والتوصية.
- **الألوان:** كحلي داكن يعبّر عن الثقة، مع تركواز مميز للحالة السليمة، وكهرماني/أحمر محصوران في التحذيرات بحسب الشدة.
- **التخطيط:** شريط جانبي ثابت على سطح المكتب، مساحة عمل ذات عمود محتوى مرن، وبطاقات أفقية قابلة لإعادة الترتيب على الجوال.
- **عناصر مميزة:** شارة تفويض الأصل؛ شريط درجة أمن مرتبط باتجاه التغير؛ أشرطة شدة ثابتة الدلالة.
- **التفاعل والحركة:** انتقالات قصيرة ودقيقة للحالات والحوارات، واحترام تقليل الحركة؛ إظهار حالة الحفظ/المهمة/الفشل مباشرة.
- **الخطوط:** Noto Sans Arabic أو system sans للعربية، مع خط واجهة sans واضح للأرقام والإنجليزية، وتراتب ثابت للعناوين والبيانات.
- **جوهر العلامة:** منصة تساعد الفرق الصغيرة على فهم وضعها الأمني ومعالجة ما ثبت وجوده. الصفات: رصينة، صريحة، عملية.
- **نبرة المنتج:** «ابدأ من الأصول التي فوّضت فحصها.» و«هذه توصية مبنية على النتائج المحفوظة، وليست إجراءً نُفّذ تلقائياً.»
- **الشعار واللون:** درع هندسي مبسط يتضمن مسار تحقق؛ اللون المميز تركواز عميق على خلفية كحلية.

## حدود واضحة

لا يوجد ضمن بيئة العمل محرك Docker متاح للفحص المباشر، لذلك ملفات Compose تُنشأ لكن لا يُدّعى اختبار تشغيل الحاويات. وحدات MFA والبريد الفعلي، كل صفحات المواصفات المؤسسية الكاملة، SOC/NIST/ISO الموثق، حملات تصيد تدريبية، والفوترة/النشر الإنتاجي تتطلب استكمالاً وتكويناً منفصلين؛ لا تُعرض كأنها مكتملة.
